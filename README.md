# PixelForge AI 🎨

**AI Portrait Generator, Image Enhancer & Background Remover for Creators**

Transform your photos into stunning AI-generated portraits, enhance images to 4K quality, remove backgrounds instantly, and generate short-form video content—all with one platform. Built specifically for Indian creators, influencers, content creators, and businesses.

## 🚀 Features

### Core Features (Production Ready)

#### 🎭 **AI Portrait Studio**
- **25+ Trending Styles** including:
  - Bollywood glamour & cinematic looks
  - LinkedIn & professional headshots
  - Artistic & illustration styles
  - Religious & cultural styles
  - Lifestyle & Instagram-trending aesthetics
- Multiple aspect ratios (portrait, square, landscape)
- Real-time preview before generation
- Template categories: Professional, Indian/Religious, Lifestyle, Artistic, Trending
- New styles added weekly

#### 🎬 **AI Video Generator**
- **Portrait Animation**: Animate your photos with natural movement
  - Subtle breathing animation
  - Dynamic cinematic movement
  - Cinematic head turns
- **Text-to-Video**: Generate cinematic 5-10 second videos
  - Fantasy, Sci-Fi, Nature, Urban & Custom styles
  - Multiple aspect ratios (16:9, 9:16, 1:1)
  - Powered by Kling v1.5 (fal.ai)
  - 30-90 second generation time

#### 📸 **Image Enhancement**
- **4K Upscaling**: Enhance any image to 4K quality
- **Deblur**: Remove motion blur and improve clarity
- **AI Super-Resolution**: Intelligent upscaling using HuggingFace models
- Works with JPG, PNG, WebP formats

#### 🧹 **Background Removal & Manipulation**
- One-click background removal
- Perfect for product photos, headshots, e-commerce
- Uses advanced ML models (@imgly/background-removal-node)

#### 🤖 **Chrome Extension** (Free)
- **Right-click any image** → "Get AI Prompt"
- Extracts AI-friendly descriptions from images
- Uses Groq AI (ultra-fast LLM)
- **10 free prompts/day** limit
- Works on Instagram, Pinterest, Twitter, and all websites
- No installation hassle for users

#### 📚 **Prompt Library** (Pro+ only)
- Save & organize generated prompts
- Export prompts for Midjourney, DALL-E, Stable Diffusion
- Tag & search saved prompts
- Community prompt sharing (future)

#### 📊 **Generation History**
- Track all created images/videos
- Compare before/after results
- Download any creation anytime
- Batch download support

- **Tailwind CSS** with custom animations
- **Framer Motion** for smooth UI transitions
- **Radix UI** (accessible components)
- **Zustand** (state management)
- **React Dropzone** (file uploads)

### Backend & Infrastructure
- **Next.js API Routes** (Edge-ready)
- **Supabase** (PostgreSQL + Auth + Storage)
- **Upstash Redis** (Rate limiting, caching)
- **Razorpay** (India-first payment gateway)

- **Replicate** (Portrait generation, enhancement)
- **HuggingFace** (Background removal, image upscaling)
